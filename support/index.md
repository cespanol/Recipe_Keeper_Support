# Recipe Keeper Simplified Support

For private help, email [info@cespanol.com](mailto:info@cespanol.com?subject=Recipe%20Keeper%20Simplified%20Support).

Settings provides Contact Support and the email address. If Mail is not set up, copy the address into your email service. The app does not attach recipes, images, links, or logs to a support message.

Include:

- App version and build number from Settings.
- iOS or iPadOS version and device type.
- The storage status shown in the app.
- The actions that caused the problem and the result you expected.
- A diagnostic event code, if the app shows one.

Share only the information needed for help. Remove private recipe content and account details from any screenshot you choose to send.

The [help website](https://cespanol.github.io/Recipe_Keeper_Support/support/) remains available. [GitHub issues](https://github.com/cespanol/Recipe_Keeper_Support/issues/new?template=support.yml) are optional and public. Keep recipe content, photos, source links, clipboard contents, file paths, iCloud identifiers, and personal account details out of public issues.

## Safe first steps

1. Keep any existing library backup.
2. Check free device storage and the internet connection.
3. For iCloud problems, check iCloud Drive and the Apple Account on each device.
4. Restart the app and try once more.
5. Contact support before deleting or reinstalling the app. Local recipes may need a verified backup or same-account iCloud recovery.

## Draft recovery

Manual recipe drafts stay on this device until Save, Discard, or Delete All Data. Use Resume Draft in Add Recipe to return to unfinished work. An edit draft does not change the saved recipe until Save. If the saved recipe changed elsewhere, check the recovery message before continuing.

Import Review saves editable recipe fields locally for recovery. Use Save for Later to close the review and return later. Extra original-source retention requires a separate choice in More. Import fields expire seven days after editing or resuming. Retained source expires seven days after the explicit retention choice.

Source editing uses a working copy. Check the preview before Apply. Cancel keeps the current recipe fields. Original observations remain separate from edited fields. Working copies, previews, and Undo history do not survive draft recovery.

Saved Original Text is evidence. Make recipe corrections in the recipe fields. Original Text is read-only; Clear removes it only when the recipe is saved.

If draft saving fails, keep the editor open and try again. Do not reinstall the app to solve a draft problem.
